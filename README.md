# PartsFinder

Веб-приложение для поиска автомобильных запчастей по артикулу с использованием веб-сервиса «Проценка».

## Возможности

- Поиск запчастей по артикулу.
- Получение списка производителей для найденной детали.
- Выбор производителя и поиск предложений.
- Отображение оригинальных позиций и аналогов.
- Просмотр цен и доступного количества.
- Обработка состояний загрузки, ошибок API и сетевых ошибок.
- Постепенное отображение большого списка предложений.

## Технологии

- **React** — пользовательский интерфейс.
- **Redux Toolkit** — управление состоянием и асинхронными запросами.
- **React Redux** — взаимодействие компонентов с Redux store.
- **Bootstrap 5** — стилизация и адаптивная вёрстка.
- **Vite** — сборка и локальный сервер разработки.

## Запуск проекта

### Требования

- Node.js
- npm

### Установка

Клонировать репозиторий:

```bash
git clone https://github.com/ExperienceTester/parts-finder.git
cd parts-finder
```

Установить зависимости:

```bash
npm install
```

Создать файл `.env` на основе примера:

```bash
cp .env.example .env
```

Указать API-ключ веб-сервиса в `.env`:

```env
VITE_API_KEY=your_api_key
```

Запустить сервер разработки:

```bash
npm run dev
```

После запуска приложение будет доступно по адресу, указанному Vite в терминале (по умолчанию `http://localhost:5173`).

## Доступные команды

| Команда           | Назначение                           |

## API

Для получения информации о запчастях используется API веб-сервиса «Проценка».

Для работы приложения необходим API-ключ, который указывается в переменной `VITE_API_KEY` файла `.env` (пример — в `.env.example`). Для проверки можно использовать тестовый ключ из документации сервиса: `00000000-0000-0000-0000-000000000001`.

Запросы из приложения отправляются на `/api`. Vite проксирует их на сервер веб-сервиса в режимах `npm run dev` и `npm run preview` (настройка в `vite.config.js`), поэтому ограничений CORS при локальном запуске нет.

При развёртывании собранного приложения (`dist/`) на собственном сервере проксирование `/api` необходимо настроить на стороне сервера (например, в nginx), так как API работает по HTTP и не отдаёт CORS-заголовки.
